# Cafe-Sales-and-Product-Insights-Dashboard

 ##  📌Project overview
 This project presents an interactive **Power BI dashboard** developed to analyze cafe sales performance and generate actionable business insights from transactional data. The dashboard provides a comprehensive view of key business metrics, including revenue, orders, product performance, store performance, and customer purchasing trends.
Using **Power Query** for data cleaning and transformation and **DAX** for creating calculated measures and KPIs, the dashboard enables users to monitor sales trends, identify top-performing products, compare store locations, analyze peak sales hours, and evaluate weekday versus weekend performance.
## 📂 Dataset
The dataset used in this project was sourced from **Kaggle** and contains transactional cafe sales data, including order details, product information, store locations, quantities, prices, and transaction dates.
| Column Name | Description |
|-------------|-------------|
| transaction_id | Unique identifier for each transaction |
| transaction_date | Date of the transaction |
| transaction_time | Time of the transaction |
| transaction_qty | Quantity of items purchased |
| store_id | Unique identifier for the store |
| store_location | Location of the store |
| product_id | Unique identifier for the product |
| unit_price | Price per unit of the product |
| product_category | Product category (e.g., Coffee, Tea, Bakery) |
| product_type | Specific type of product |
| product_detail | Detailed product name |

## 🎯 Business Objectives
- Analyze overall sales performance.
- Identify top-selling products and categories.
- Monitor monthly revenue trends.
- Time-of-Day Sales Analysis
- Compare weekday and weekend sales performance.
- Identify peak sales hours.
- Evaluate store-wise performance.
- Support data-driven business decisions through interactive dashboards.
## 📈 Results
- Identified a **32.0% month-over-month revenue growth** from April to May.
- Determined that **72.1% of total revenue** was generated on weekdays.
- Identified **Barista Espresso** as the highest-performing product type, contributing **13.3% of total revenue**.
- Found that **Sustainable Grown Organic** was the top revenue-generating product detail.
- Revealed that **8:00 AM–10:00 AM** was the peak sales period, providing insights for staffing and inventory optimization.
- Identified **Hell's Kitchen** as the top-performing store location based on revenue, order volume, and quantity sold.
- Delivered an interactive dashboard with dynamic slicers and KPI metrics, enabling efficient analysis of sales performance across products, stores, and time periods.
